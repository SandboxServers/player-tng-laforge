# Day 712

Held still in the row all day, health 20, hunger 20, wooden sword in pack, no food. Picard, Riker, Jason, Chapman and Worf all answered the morning greeting and held for Billy's named call; none came yet. MacDonald (health 11, hunger 16) has three potatoes and is waiting for Billy's word. Riker heard a bow to the northwest. At dusk I tried to use the bed at 429,107,-1065; the game said that block is a bed, so I slept by the sleep action next to it instead. Wesley still has no working bed near 416,107,-1050. No walk was named for me, and the dropped pile at 413,107,-1042 stays where it is.
